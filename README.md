# Alfa Porudžbine - Android aplikacija

Ovo je nativni Android projekat za organizer porudžbina.

## Kako da napraviš APK

1. Instaliraj Android Studio.
2. Otvori folder `alfa_orders_android` kao postojeći projekat.
3. Sačekaj da Android Studio uradi Gradle Sync.
4. Izaberi **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. APK će biti u `app/build/outputs/apk/debug/`.

## Funkcije

- Dodavanje porudžbine
- Kupac, telefon, proizvod, cena, rok i napomena
- Statusi: Nova, U izradi, Spremno, Isporučeno
- Pretraga po kupcu, proizvodu i broju porudžbine
- Filter po statusu
- Ukupan iznos i broj hitnih porudžbina
- Čuvanje porudžbina lokalno na telefonu
